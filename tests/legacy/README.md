# Historical tests from the original upload

These original scripts are preserved for traceability. Several intentionally obsolete assertions expect simulated LLM thinking tags, fabricated high confidence, unsupported safety defaults, or exact answers to training examples. They are not the current correctness gate and are not claimed to pass on version 0.2.

Run `python -m pytest` from the repository root for the maintained, isolated regression suite in `tests/regression`. Historical scenarios may be migrated only when their required outcome is scientifically and technically justified; do not restore misleading output merely to satisfy an old assertion.
